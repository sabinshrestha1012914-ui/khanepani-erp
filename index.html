मोबाइल र कम्प्युटर (PC) एप इन्स्टल गाइड

iPhone / iPad (Safari) मा एप बनाउने तरिका:
  1. Safari ब्राउजरको तल (वा माथि) रहेको Share (↑) बटनमा थिच्नुहोस्।
  2. तल स्क्रोल गरेर "Add to Home Screen" मा ट्याप गर्नुहोस्।
  3. माथि दायाँ Add थिच्नुहोस् — होम स्क्रिनमा एप बन्छ!
Android मोबाइल (Chrome) मा इन्स्टल गर्ने तरिका:
  1. Chrome ब्राउजरको माथि दायाँ ३ थोप्ला (⋮) मेनुमा थिच्नुहोस्।
  2. "Install app" वा "Add to Home screen" छान्नुहोस्।
Windows / Mac कम्प्युटर (PC) सफ्टवेयर बनाउने तरिका:
  1. Chrome वा Microsoft Edge मा एड्रेस बारको दायाँ छेउमा देखिने Install (⊕ / 💻) आइकनमा क्लिक गर्नुहोस्।
  2. वा ब्राउजर मेनु (⋮) → Cast, save, and share → Install page as app थिच्नुहोस्। Desktop र Start Menu मा सिधै सफ्टवेयर सर्टकट बन्छ!
✓ पछि GitHub मा सफ्टवेयर अपडेट गर्दा मोबाइल एप र PC सफ्टवेयर दुवै इन्टरनेट जोडिनासाथ स्वतः अपडेट हुन्छन् र Firebase Cloud डाटा एउटै रहन्छ।
